# MM-15 command reference

Generated by `mm_15 --commands` from the dispatch table; do not edit by hand.
Stack pictures read deepest-first: `y x -- y+x` consumes Y and X and leaves the sum in X.

## Arithmetic

| Command | Stack | Description | Example |
|---|---|---|---|
| `+` | `y x -- y+x` | add scalars or matrices; a scalar added to a matrix is added elementwise | `3 4 +` |
| `-` | `y x -- y-x` | subtract scalars or matrices (a scalar elementwise) | `10 4 -` |
| `*` | `y x -- y*x` | multiply scalars, or matrix product for matrices | `[2 2 $ 1 2 3 4] [2 1 $ 1 1] *` |
| `/` | `y x -- y/x` | divide scalars, or a matrix by a scalar; division by zero is an error | `1 3 /` |
| `^` | `y x -- y^x` | power; a square matrix to an integer power is a matrix power; a negative base with a fractional exponent promotes to complex | `2 10 ^` |
| `pow` | `y x -- y^x` | power (alias of ^) | `2 10 pow` |
| `.*` | `A B -- A.*B` | elementwise matrix product | `[2 2 $ 1 2 3 4] [2 2 $ 1 1 2 2] .*` |
| `./` | `A B -- A./B` | elementwise division (matrix or scalar operands) | `[2 2 $ 1 2 3 4] [2 2 $ 1 2 1 2] ./` |
| `.^` | `A B -- A.^B` | elementwise power (matrix or scalar operands) | `[2 2 $ 1 2 3 4] 2 .^` |
| `chs` | `x -- -x` | change sign (elementwise for matrices) | `5 chs` |
| `inv` | `x -- 1/x` | reciprocal (elementwise for matrices; see minv for the matrix inverse) | `4 inv` |
| `abs` | `z -- \|z\|` | absolute value; magnitude for complex; elementwise for matrices | `(3,4) abs` |
| `sqrt` | `x -- sqrt(x)` | square root; a negative real promotes to complex | `-4 sqrt` |
| `%` | `y x -- y y*x/100` | percent of y (HP %; keeps y) | `200 25 %` |
| `%t` | `y x -- y 100*x/y` | x as a percent of the total y (HP %T; keeps y) | `200 50 %t` |
| `%chg` | `y x -- y 100*(x-y)/y` | percent change from y to x (HP delta%; keeps y) | `80 100 %chg` |
| `mod` | `y x -- y mod x` | floored modulo (result has the sign of x) | `-7 3 mod` |
| `fact` | `x -- x!` | factorial; Gamma(x+1) for non-integers | `5 fact` |
| `ncr` | `n k -- C(n,k)` | combinations | `52 5 ncr` |
| `npr` | `n k -- P(n,k)` | permutations | `10 3 npr` |
| `frac` | `x -- frac(x)` | fractional part, x - intg(x), with the sign of x | `3.7 frac` |
| `intg` | `x -- int(x)` | integer part, truncated toward zero as on HP calculators (-3.7 gives -3) | `3.7 intg` |
