> **Archived.** MM-15 2.1 was restructured into [MM-41](https://github.com/micomrkaic/MM-41),
> which runs every MM-15 command, word and program unchanged (binary `mm41`,
> configuration in `~/.config/mm41/`; `predefined_macros.txt` became the `std`
> word module). MM-41 adds plug-in modules, exact decimal numbers and a finance
> module, and is where all further development happens. The MM-15 manual and
> source remain here for reference; see MM-41's *Coming from MM-15* appendix for
> the handful of differences.
